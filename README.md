# Wine Quality Classification — Model Comparison & Streamlit Demo

## a. Problem statement
Predicting whether a wine is "good" (quality ≥ 7) or not, from its
physicochemical properties, using 5 classification models.

## b. Dataset description
- Source: UCI Machine Learning Repository — Wine Quality (Cortez et al., 2009)
  https://archive.ics.uci.edu/ml/datasets/wine+quality
- 6,497 instances (1,599 red + 4,898 white), 12 features
- Features: 11 physicochemical measurements + wine type (red/white)
- Target: quality ≥ 7 binarized to "good" (1) vs "not good" (0)
